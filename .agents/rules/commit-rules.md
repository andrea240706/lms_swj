# Aturan Pesan Git Commit

- Buat pesan commit sesuai instruksi tugas yang telah selesai dikerjakan.
- Ketika pengguna memerintahkan commit, gunakan struktur universal yang mudah dipahami (format: `feat: ...`, `fix: ...`, `refactor: ...`).
- WAJIB gunakan kalimat singkat dan padat dalam Bahasa Indonesia.
- Pastikan pesan commit langsung menjelaskan perubahan utama dan mudah dimengerti. Aturan ini berlaku selamanya.
